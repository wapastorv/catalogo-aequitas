# Catálogo AEQUITAS JURÍDICA

Catálogo digital de servicios legales y financieros (Bogotá, D.C. · Vigencia 2026 - 2027).

## Estructura

```
index.html              → contenido (8 páginas)
assets/css/styles.css   → estilos
assets/js/main.js       → botón «Guardar como PDF»
assets/img/             → imágenes
```

## Uso

Abra `index.html` en el navegador. Para exportar, pulse **Descargar / Guardar como PDF**,
elija «Guardar como PDF», márgenes «Ninguno» y active «Gráficos de fondo».
